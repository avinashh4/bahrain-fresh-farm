BAHRAIN FRESH FARM — 5 PAGE WEBSITE

Open index.html in your browser. Use the navigation to view all five pages.
The shopping basket works across pages using browser localStorage. Checkout opens WhatsApp with a prefilled order for +973 3371 1119; the customer must press Send.

Prices are sample BHD prices and should be replaced with confirmed prices before publishing. Product and animal photos are illustrative, with some photos loaded from Unsplash (internet required). Claims about organic certification, delivery, opening hours, and animal sale availability have intentionally not been made.

To change WhatsApp number edit WHATSAPP in data.js. To change products/prices edit PRODUCTS in data.js.

To publish later upload all files and assets folder to your GitHub repo, then deploy on Vercel.
